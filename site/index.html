LESS FRICTION, MORE FLOW

少一点来回，多一点顺手。

熟悉的 Finder，多几个刚好用得上的动作。

01 / PATHS
~/project/src/main.go

路径，复制就能用。

绝对路径、相对路径、终端转义路径，一次复制。自动识别 Git 根目录，也支持自定义项目根。

02 / OPEN WITH
GoLandCursorVS CodeWorkBuddy

用你习惯的工具打开。

文件交给编辑器，目录交给 Terminal 或 iTerm。支持添加应用，并展示已安装应用的原始图标。

03 / FILE ACTIONS
.md.json.swift.go

文件小事，就地处理。

新建文件、复制或移动到常用目录、计算校验值、显示隐藏文件。需要的留下，不用的在设置中关闭。

GIT WORKSPACE

看清改动，再整理历史。

从目录进入提交历史，把比较、整理和冲突处理放在一个原生面板里。

找到提交，逐文件看差异。

按说明、作者或 SHA 搜索历史，定位 HEAD、跳转父提交。比较两条提交或分支快照，在文件树中切换高亮 Diff，按需读取单个文件。

复杂操作，先确认影响。

拣选提交、修改说明、丢弃、squash/fixup 和重排。执行前核对目标与受影响范围；遇到冲突可解决后继续，或中止整个操作。Revert 新增撤销提交，reset 提供 soft、mixed、hard 模式。

操作的同时，学会命令。

命令预览随选项变化，可展开 rebase 的 todo 与辅助文件。执行后查看结果和脱敏操作记录。复制命令前会明确提示所需的辅助文件。

从一个目录开始。

在 Finder 中右键仓库文件夹或目录内空白处，选择 SuperMenu → Git 提交历史。也可从菜单栏打开仓库，或在应用中按 ⌘O；文件夹选择器支持 ⌘⇧G 输入路径。

当前支持范围

仅操作本地仓库，不自动推送。历史修改前需处理工作区改动；重放范围包含 merge 时会拒绝执行，拣选也暂不支持 merge 提交。支持提交／分支快照比较，与暂存区和工作目录比较尚未提供。远端提示依据本地已知引用，不代表实时远端状态。

MAKE YOURSELF AT HOME

从这里开始。

目前提供源码构建。准备一台 Apple Silicon Mac、macOS 14 或更新版本，以及 Xcode Command Line Tools (Swift 6+)。

尚未发布预编译安装包。当前构建使用本地签名，未做公证。

完整安装说明 ↗
1

构建并安装

先安装 Command Line Tools，再运行以下命令。

xcode-select --install 
git clone https://github.com/openmacapp/supermenu.git
cd supermenu
zsh scripts/build.sh
zsh scripts/install.sh
open "$HOME/Applications/SuperMenu.app"
2

启用 Finder 扩展

打开应用的「启用」页，点击「打开访达扩展设置」，在系统设置中启用 SuperMenu。

3

回到 Finder，右键一下

选择文件或文件夹，展开「超级右键」。也可以在窗口空白处操作当前目录。

GOOD TO KNOW

还有这些小细节。

为什么右键菜单没有出现？

先在应用「启用」页确认 Finder 扩展已启用，然后重新打开 Finder 菜单。扩展入口与系统「服务」菜单是不同的；应用不会添加额外的 Finder 工具栏按钮。

需要什么权限？

Finder 扩展需要在系统设置中启用。菜单栏提供打开 Git 仓库和应用设置等入口， 不读取 Finder 选择，也不需要控制 Finder 的自动化权限。

可以切换语言和菜单功能吗？

可以。在设置中选择简体中文、日语、韩语、英语或跟随系统，也可以关闭不需要的操作。系统服务、权限提示和系统应用名称仍跟随 macOS 语言。

支持 Intel Mac 吗？

当前构建脚本固定生成 arm64 应用，面向 Apple Silicon。尚未提供或验证 Intel 构建。
